# Limit Order Book
A C++ implementation of a limit order book with price-time priority matching, built to learn C++.

## Origin
Base implementation follows [this tutorial](https://youtu.be/XeLWe0Cx_Lg), covering:
- Order placement and cancellation
- Price-time priority matching
- Partial fills

Extended with:
- [x] Tests 
- [x] Self-Trade Prevention
- [ ] FillOrKill order type
- [ ] Market order type
